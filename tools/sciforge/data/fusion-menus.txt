# Autodesk Fusion's command tree, by NAME only: the checklist tools/sciforge/parity.py compares
# with SciForge's own menus to write docs/sciforge/parity-checklist.md.
#
# This file is for us, never shown in SciForge's interface. It records names only (a command's
# name is a generic CAD term or Fusion's label, kept as a checklist entry); no descriptions,
# icons or wording of Autodesk's are copied. Written from memory of stock Fusion (2024-2026
# releases), cross-checked with docs/sciforge/feature-outline.md and docs/sciforge/parity/*.md
# (which cite Autodesk's help and forum answers). Corrections are welcome: Luca can open Fusion
# and fix a line; the next run of parity.py takes it.
#
# FORMAT
#   - One name per line; "#" starts a comment line; blank lines are ignored.
#   - Indentation is 2 spaces per level. Level 0 is an AREA (a ribbon tab, a menu, a context
#     menu). Level 1 is usually a PANEL (CREATE, MODIFY...) or a node type. A line with lines
#     under it is a heading (a panel or a submenu): it is not counted itself, only the lines
#     without children (the commands) are counted.
#   - A trailing "?" means the name or its place is not sure (it is counted all the same; the
#     checklist marks it so someone can confirm it in Fusion).
#   - Attributes in square brackets at the end of a line apply to that line and everything
#     under it:
#       [in=SCOPE,SCOPE]  where parity.py looks for the command in SciForge. Scopes:
#                         tab:<id> (a ribbon tab of ribbon_config.TABS: solid, surface, mesh,
#                         utilities, sketch, drawing, sheet_metal, plastic, flat_pattern),
#                         file (the File menu), quick (the
#                         application bar), nav (navigation bar), workspace (the workspace
#                         button's menu), marking (right-click marking menu), sketch-marking
#                         (the marking menu inside a sketch), browser or browser:<node kind>
#                         (browser right-click menus, browser_core.MENUS), timeline:step,
#                         timeline:group, timeline:settings, timeline:playback, viewcube,
#                         sheets (a drawing's sheet bar).
#       [out=REASON]      left out of SciForge on purpose (feature-outline.md section 8, or a
#                         decision of Luca's in MEMORY.md). Counted in the overall figure, left
#                         out of the "areas SciForge builds" figure.
#   - Panels Fusion repeats on several tabs (CONSTRUCT, INSPECT, INSERT, SELECT, and the shared
#     MODIFY commands such as Physical Material) are listed once, under SOLID. A command that
#     appears in two genuinely different places (Delete in MODIFY and in the marking menu) is
#     listed in both: the checklist counts menu entries, like a user hunting for a command.
#   - Not covered: dialog options (Extrude's Taper, Fillet's types...), the Sketch Palette's
#     check boxes, keyboard-only actions, the Data Panel, Help and account menus.
